# OX 퀴즈 돌다리 게임

100개의 OX 퀴즈를 풀며 돌다리를 건너고, 망치 10개를 모아 최종 목적지에 집을 짓는 게임입니다.

## 게임 방법

1. 돌다리의 돌을 클릭하여 OX 퀴즈를 풉니다
2. 정답을 맞추면 다음 스테이지로 진행합니다
3. 10, 20, 30... 90번째 스테이지는 특별 스테이지로, 정답 시 하트 또는 망치를 선택할 수 있습니다
4. 오답 시 하트를 사용하여 계속 진행하거나 게임 오버됩니다
5. 100번째 스테이지에 도착하여 망치 10개를 모으면 승리합니다!

## 기술 스택

- React 19
- TypeScript
- Vite
- CSS3

## 개발 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 빌드 미리보기
npm run preview
```

## 특징

- 200개의 다양한 카테고리 퀴즈 (동물, 식물, 역사, 과학, 산리오, 짱구, 산수, 인물, 나라)
- 매 게임마다 100개 랜덤 선택 (중복 없음)
- LocalStorage를 활용한 망치 누적 시스템
- 원근감 있는 돌다리 렌더링
- 반응형 디자인
